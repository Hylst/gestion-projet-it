## Règles

- Une spec validée ne se réécrit pas silencieusement : une nouvelle décision ajoute un avenant daté.
- Un plan décrit une exécution, pas une intention permanente.
- Le backlog porte les priorités ; il ne remplace pas une spec.
- Le changelog décrit ce qui est publié et vérifié.
