# Audit WCAG 2.2 AA des nouvelles pages

**Date :** 24 octobre 2026
**Statut :** conforme pour le périmètre du lot
**Périmètre :** guides « erreurs et décision » des neuf modules et page `/ressources`.

## 1. Méthode

- Revue de structure et de sémantique dans les tests de composants.
- Smoke Playwright sur les 19 routes, les liens internes, les ancres et le clavier.
- Lighthouse mobile sur `/ressources` et `/module-1`.
- Vérification des contrastes, des labels, du focus et des liens externes.
- Contrôle des 24 ressources : 24 URL en réponse HTTP 200 le 24 octobre 2026.

## 2. Résultats

| Contrôle | Résultat |
| --- | --- |
| Langue de la page | `lang="fr"` dans `index.html` |
| Titre et description par route | `SeoHead` sur les neuf modules et `/ressources` |
| Titre principal | Un seul `h1` par page |
| Hiérarchie | `h1`, `h2`, `h3`, `h4` dans les guides et la bibliothèque |
| Repères | `header`, `nav`, `main`, `footer` |
| Lien d’évitement | Présent et focalisable |
| Sommaire | Ancres `#guide` et `#module-1` à `#module-9` valides |
| Focus visible | Contour global sur liens, boutons, champs et éléments focusables |
| Navigation clavier | Smoke clavier sur les labos et les liens de ressources |
| Liens externes | `target="_blank"` et `rel="noopener noreferrer"` |
| Libellé des liens | Texte visible, complément « nouvel onglet » en lecture d’écran |
| Contrastes | Aucun échec `color-contrast` dans Lighthouse |
| Mouvement | Respect de `prefers-reduced-motion` |
| Chargement externe | Aucun chargement automatique |

## 3. Lighthouse mobile

| Page | Performance | Accessibilité | Contraste |
| --- | --- | --- | --- |
| `/ressources` | 99 | 100 | 0 échec |
| `/module-1` | 99 | 100 | 0 échec |

Le CLI Lighthouse sort avec le code 1 sous Windows lors du nettoyage du profil temporaire (`EPERM`). Les rapports JSON produits sont complets et les scores sont lus depuis ces fichiers.

## 4. Tests et smoke

- `npm test` : 36 fichiers, 220 tests passés au moment de l’audit.
- `npm run lint` : aucune erreur.
- `npm run typecheck` : aucune erreur.
- `npm run build` : build production réussi.
- Smoke Playwright : 11 tests passés, 19 routes rechargées, zéro erreur console, zéro requête externe au chargement.
- Test dédié : focus sur le premier lien externe de `/ressources`, attributs de sécurité vérifiés, tabulation suivante visible.

## 5. Limites

- Pas de test avec un lecteur d’écran réel dans ce lot.
- Les parcours Produit et Cybersécurité ne sont pas encore ouverts ; leur audit complet sera refait à leur livraison.
- Les ressources externes sont vérifiées par URL et lecture humaine, pas par audit du contenu de chaque site.
- Les scores Lighthouse dépendent du poste et du réseau local.

## 6. Décision

Les pages nouvelles du lot sont conformes aux critères vérifiés de WCAG 2.2 AA. L’audit sera complété à l’ouverture des parcours et lors de la prochaine revue annuelle des ressources.
