## Z-Image-Turbo

Z-Image-Turbo est un modèle local sous licence Apache 2.0. Il a été utilisé comme outil de création graphique. Aucune image raster générée par ce modèle n’est présente dans le build 1.4.0. Tout ajout futur sera inscrit dans ce tableau avec le fichier, la date et la licence.

## Règles

- Aucune personne réelle, aucun visage réel, aucun deepfake.
- Aucune donnée personnelle dans les prompts.
- Aucun appel à un service d’IA externe au runtime.
- Les illustrations restent décoratives ou explicatives et sont accompagnées de texte accessible.
- Aucune revendication de droit d’auteur n’est formulée sur les sorties générées au-delà du droit applicable.
